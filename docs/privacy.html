개인정보 처리방침

AI 리포트 (AI Usage Checkup) · 시행일 2026년 6월 15일

AI 리포트(이하 "앱")는 사용자의 Claude Code 사용 기록을 본인의 컴퓨터 안에서만 분석해 사용 습관 리포트를 만들어 주는 데스크탑 앱입니다. 분석에 쓰이는 대화·세션 기록은 앱 밖으로 전송되지 않으며, 외부 서버로 나가는 정보는 아래에 명시한 익명 점수와 선택한 닉네임으로 한정됩니다.

핵심 요약: 분석은 100% 로컬에서 동작합니다. 별도의 로그인이나 계정이 없으며, 이메일·실명·연락처·위치 정보를 일절 수집하지 않습니다. 세션 대화 내용, 프롬프트, 파일 경로, 프로젝트 이름은 서버로 전송되지 않습니다.

1. 수집·전송하는 정보

앱의 "순위(랭킹)" 기능을 위해, 분석을 마칠 때 다음 정보만 익명 랭킹 서버로 전송됩니다.

익명 설치 식별자앱을 처음 실행할 때 무작위로 생성되는 UUID입니다. 로그인이나 개인 식별 정보와 연결되지 않으며, 같은 설치본이 다시 분석할 때 내 점수 1행을 갱신하는 용도로만 쓰입니다.
분석 점수종합 평균 점수와 항목별 점수(숫자값)입니다. 원본 대화가 아니라 집계된 수치만 전송됩니다.
앱 버전점수 해석 기준이 버전마다 달라, 버전 문자열을 함께 저장합니다.
닉네임 (선택)리더보드에 공개적으로 표시할 이름입니다. 사용자가 직접 입력할 때만 전송되며, 입력하지 않으면 "익명"으로 표시됩니다. 실명을 적도록 요구하지 않습니다.

2. 수집하지 않는 정보

  • Claude Code 세션의 대화 내용, 프롬프트, 응답
  • 파일 경로, 프로젝트 이름, 폴더 구조
  • 실명, 이메일 주소, 전화번호, 위치 정보
  • 광고 식별자, 기기 광고 추적 정보

앱에는 로그인·회원가입 절차가 없습니다.

3. 정보를 이용하는 목적

전송된 익명 점수와 닉네임은 오직 다른 사용자 대비 내 순위(퍼센타일·티어)를 계산해 리더보드에 표시하는 데에만 사용됩니다. 마케팅, 광고, 프로파일링, 제3자 판매에 사용하지 않습니다.

4. 데이터 보관 및 위치

랭킹 데이터는 Supabase(Supabase, Inc.)가 운영하는 관리형 데이터베이스의 서울 리전에 저장됩니다. 설치 식별자당 최신 점수 1행만 보관하며, 다시 분석하면 기존 행을 덮어씁니다. 데이터베이스는 행 수준 보안(RLS)으로 보호되어, 공개 API 키로는 다른 사용자의 점수를 직접 조회하거나 삭제할 수 없습니다.

분석 스냅샷(추이 기록)과 설정값(닉네임·설치 식별자)은 서버가 아니라 본인 컴퓨터의 앱 데이터 폴더에 저장됩니다.

5. 제3자 제공

데이터를 제3자에게 판매하거나 광고·분석 목적으로 공유하지 않습니다. 위 4항의 Supabase는 데이터 저장을 위한 인프라 제공자(수탁 처리자)이며, 그 외 외부 추적·분석 도구는 포함되어 있지 않습니다.

6. 데이터 삭제 요청

서버에 저장된 내 랭킹 데이터의 삭제를 원하시면, 아래 문의 이메일로 사용 중인 닉네임 또는 설치 식별자를 알려 주세요. 확인 후 해당 행을 삭제해 드립니다. 앱을 삭제(제거)하더라도 이미 서버에 저장된 행은 자동으로 지워지지 않으므로, 완전한 삭제를 원하시면 별도로 요청해 주세요.

7. 아동의 개인정보

본 앱은 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

8. 처리방침의 변경

본 처리방침은 법령 또는 앱 기능 변경에 따라 개정될 수 있으며, 변경 시 이 페이지에 갱신된 내용과 시행일을 게시합니다.
